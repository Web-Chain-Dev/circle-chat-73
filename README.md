# Circle Chat (73)

Build a chat application interface inspired closely by Telegram Web. It must have a clean, dark-mode default chat layout (left sidebar for chat list, right side for active chat window). Implement full real-time messaging using Supabase. Include user authentication. It must also have the ability audio messages, and also video messages(кружки), like telegram does. In the interface give the user the ability to have audio and video calls but don't make the functionality for it, just have the buttons there for the future
